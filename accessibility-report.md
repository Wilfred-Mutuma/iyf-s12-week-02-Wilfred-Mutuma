# Accessibility Report

## Introduction

I reviewed my portfolio website with accessibility in mind.
The goal was to make the website easier to use for different
users, including people who use assistive technologies.

## Accessibility Issues Checked

### 1. Images

Images should have alternative text so that screen readers can
describe them to users.

### 2. Form Labels

The contact form uses labels connected to the corresponding
form fields.

### 3. Required Fields

Important contact form fields are marked as required.

### 4. Semantic HTML

The website uses semantic elements such as:

- header
- nav
- main
- section
- article
- aside
- footer

These elements provide a clear structure for the webpage.

### 5. Navigation

The navigation menu is available across the main pages of
the portfolio.

The current page is identified using `aria-current="page"`.

## Accessibility Improvements

I added descriptive alternative text to images, labels to form
fields, required attributes to important inputs, and semantic
HTML elements.

## Lighthouse Accessibility Score

I will record the final Lighthouse accessibility score after
running an accessibility audit on the completed website.

**Final Score: 100/100**

## Conclusion

The accessibility review helped me understand the importance
of creating websites that are usable by as many people as possible.
