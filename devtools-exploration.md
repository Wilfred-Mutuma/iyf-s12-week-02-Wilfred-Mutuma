# DevTools Exploration

## Introduction

I used Chrome DevTools to explore how websites are structured,
styled, and loaded by the browser.

## 1. Elements Panel

The Elements panel allows me to inspect the HTML structure of a webpage.

I was able to see elements such as headings, paragraphs, links,
images, and other HTML elements.

## 2. Styles Panel

The Styles panel shows the CSS rules applied to HTML elements.

I could see properties such as:

- font-size
- color
- margin
- padding
- width
- display

## 3. Console Panel

The Console is used to view JavaScript messages, warnings,
and errors.

It can also be used to test JavaScript commands.

## 4. Network Panel

The Network panel shows resources requested by the webpage,
such as HTML files, CSS files, JavaScript files, and images.

Reloading the page allowed me to observe these network requests.

## 5. What I Learned

Chrome DevTools is useful for understanding how websites work
and for finding and fixing HTML, CSS, and JavaScript problems.

It will be useful when developing and debugging my own websites.
